# NG-App

**Android-App für Kalender, Angebote und die Organisation des Alltags.**

NG-App bündelt Kalender, Angebots-/Prospektansicht und Einkaufslisten. Weitere im Projekt dokumentierte Bereiche sind Konto/Anmeldung, Scanner und Authenticator. Umfang und Abnahme unterscheiden sich je Entwicklungsstand; dieses Repository verspricht keine vollständige Geräteabnahme.

## Aktueller Stand · 01.11.2026

- Die Veröffentlichung eines neuen Android App Bundles mit **VersionCode 38 im internen Google-Play-Test** wurde vom Projektinhaber gemeldet.
- Das ist **keine bestätigte allgemeine Produktionsfreigabe**. Die aktuelle Play-Console-Zuordnung und das konkrete Paket wurden in dieser Dokumentationspflege nicht unabhängig geprüft.
- Für Anmeldung/Biometrie wurde anschließend ein Bedienungsproblem gemeldet. Eine vereinfachte Anmeldung und ein übersichtlicheres Kontomenü sind beauftragt; ein korrigierter Build ist hier noch nicht bestätigt.
